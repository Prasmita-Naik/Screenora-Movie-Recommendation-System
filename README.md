

\# Screenora - Movie and Series Recommendation System



Screenora is a movie and TV series recommendation web application

developed using Python and Streamlit.



The application allows users to explore movies and series, search

for titles using semantic search, view IMDb ratings, and discover

similar content.



\## Features



\- Movie and TV series recommendations

\- AI-based semantic search

\- Trending and top-rated sections

\- Movie and series posters using TMDB API

\- Genre-based filtering

\- IMDb ratings and movie details

\- Similar content recommendations

\- Personal watchlist



\## Technologies Used



\- Python

\- Streamlit

\- Pandas

\- NumPy

\- Scikit-learn / Sentence Transformers

\- FAISS

\- TMDB API



\## Project Structure



\- movie\_app.py

\- titles\_new.csv

\- credits\_new.csv

\- requirements.txt



\## Installation



1\. Clone the repository:



&#x20;  git clone YOUR\_GITHUB\_REPOSITORY\_URL



2\. Navigate to the project folder:



&#x20;  cd Project\_Movie



3\. Install dependencies:



&#x20;  pip install -r requirements.txt



4\. Run the application:



&#x20;  streamlit run movie\_app.py



\## API Configuration



Get a TMDB API key from:



https://www.themoviedb.org/settings/api



Enter your API key in the application sidebar.
